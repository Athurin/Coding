[239. 滑动窗口最大值 - 力扣（LeetCode）](https://leetcode.cn/problems/sliding-window-maximum/description/)

AC1: 使用双端队列设计单调队列数据结构。
```cpp
class Solution 
{
public:
    class MyQueue
    {
    public:
        deque<int> que;
        void pop(int value)
        {
            if(!que.empty() && value == que.front())
                que.pop_front();
        }
        void push(int value)
        {
            while(!que.empty() && value > que.back())
                que.pop_back();
            
            que.push_back(value);
        }

        //查询最大元素
        int front()
        {
            return que.front();
        }
    };

    vector<int> maxSlidingWindow(vector<int>& nums, int k) 
    {
        MyQueue que;
        vector<int> result;

        for(int i=0; i<k; i++)
            que.push(nums[i]);

        result.push_back(que.front());

        for(int i=k; i<nums.size(); i++)
        {
            que.pop(nums[i-k]);
            que.push(nums[i]);
            result.push_back(que.front());
        }
        return result;
    }
};
```

AC2:
```cpp
class Solution 
{
    class MyQueue
    {
    public:
        deque<int> que; //单调队列

        //弹出元素，由于单调队列只维护最值，该元素可能已不再队列当中
        void pop(int value)
        {
            if(!que.empty() && que.front() == value) que.pop_front();
        }

        void push(int value) //单调递减维护最大值
        {
            while(!que.empty() && value > que.back())
                que.pop_back();
            que.push_back(value);
        }

        int front() //队首是最大值
        {
            return que.front();
        }
    };

public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) 
    {
        MyQueue que;
        vector<int> res;

        for(int i=0; i<k; i++)
            que.push(nums[i]);
        //res.push_back(que.front());

        for(int i=k; i<nums.size(); i++)
        {
            // que.pop(nums[i-k]); //弹出滑动窗口的左端
            // que.push(nums[i]);
            res.push_back(que.front());
            que.pop(nums[i-k]); //弹出滑动窗口的左端
            que.push(nums[i]);
        }
        res.push_back(que.front());

        return res;
    }
};
```

注意：
pop函数中，判断的是逻辑等于，原因是“由于单调队列只维护最值，该元素可能已不再队列当中”：
```cpp
if(!que.empty() && que.front() == value) que.pop_front();
```

push中是严格单增
```cpp
while(!que.empty() && value > que.back())
```



AI样例模拟：
看个例子（窗口大小为 3）：
数组：`[-7, -8, 7, 5, 7, 1, 6, 0]`

我们关注**第二个 `7`**（索引 4）：

严格单调（`>`）：
- 窗口 `[5, 7, 1]`，队列是 `[7, 1]`，**最大值是 7**，**只有一个 7**。

 非严格单调（`>=`）：
- 窗口 `[5, 7, 1]`，队列变成 `[7, 1]`，**看起来一样**，但：
- **前一个 7（索引 2）被新 7“挤掉”了**，**你丢失了历史信息**。

---
❗真正的问题来了：**滑动窗口弹出时**

假设你现在窗口滑动，**要弹出索引 2 的那个 7**：

- **严格单调**：队列里是 `[7, 1]`，**这个 7 是索引 4 的**，**索引 2 的 7 早已被弹出**，**你不会误删**。
- **非严格单调**：**两个 7 都被保留**，**你会误以为索引 2 的 7 还在队列里**，**结果你弹出时误删了索引 4 的 7**，**队列变成 `[1]`**，**最大值变成 1**，**错误！**

---
✅ 总结一句话：

> **压入时必须使用严格单调（`>` 或 `<`），否则相等值会重复入队，导致滑出窗口时误删“后来的”最值，从而返回错误结果。**
