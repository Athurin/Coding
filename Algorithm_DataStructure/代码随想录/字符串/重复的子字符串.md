### 移动匹配
[代码随想录](https://www.programmercarl.com/0459.%E9%87%8D%E5%A4%8D%E7%9A%84%E5%AD%90%E5%AD%97%E7%AC%A6%E4%B8%B2.html#%E6%80%9D%E8%B7%AF)

结论先行：**所以判断字符串s是否由重复子串组成，只要两个s拼接在一起，里面还出现一个s的话，就说明是由重复子串组成。**

充分性和必要性证明见[代码随想录](https://www.programmercarl.com/0459.%E9%87%8D%E5%A4%8D%E7%9A%84%E5%AD%90%E5%AD%97%E7%AC%A6%E4%B8%B2.html#%E6%80%9D%E8%B7%AF)

- 时间复杂度: O(n)
- 空间复杂度: O(1)

不过这种解法还有一个问题，就是 我们最终还是要判断 一个字符串（s + s）是否出现过 s 的过程，大家可能直接用contains，find 之类的库函数， 却忽略了实现这些函数的时间复杂度（暴力解法是m * n，一般库函数实现为 O(m + n)）。

```cpp
class Solution 
{
public:
    bool repeatedSubstringPattern(string s) 
    {
        string t = s + s;
        t.erase(t.begin());
        t.erase(t.end()-1);

        if(t.find(s) != std::string::npos) return true;
        else return false;
    }
};
```


### KMP

利用KMP的特性，证明：[代码随想录](https://www.programmercarl.com/0459.%E9%87%8D%E5%A4%8D%E7%9A%84%E5%AD%90%E5%AD%97%E7%AC%A6%E4%B8%B2.html#%E6%80%9D%E8%B7%AF)
[459. 重复的子字符串 - 力扣（LeetCode）](https://leetcode.cn/problems/repeated-substring-pattern/solutions/386481/zhong-fu-de-zi-zi-fu-chuan-by-leetcode-solution/)

```cpp
class Solution 
{
public:
    //next数组
    void getNext(vector<int>& next, const string& needle)
    {
        int k=-1, j=0;
        next[0] = -1;
        while(j < needle.size()-1) //没有处理空串
        {
            if(k == -1 || needle[k] == needle[j])
            {
                k++;
                j++;
                next[j] = k;
            }
            else k = next[k];
        }
    }

    //kmp算法
    int strStr(string haystack, string needle) 
    {
        int lenhay = haystack.size();
        int lenndl = needle.size();
        int i=0, j=0;

        vector<int> next(lenndl);
        getNext(next, needle);

        while(i < lenhay && j < lenndl)
        {
            if(j==-1 || haystack[i] == needle[j])
            {
                i++;
                j++;
            }
            else j=next[j];
        }

        if(j >= lenndl) return i-lenndl;
        else return -1;
    }

    bool repeatedSubstringPattern(string s) 
    {
        string t = s + s;
        t.erase(t.begin());
        t.erase(t.end()-1);

        if(strStr(t, s) != -1) return true;
        else return false;
    }
};
```
