不能使用额外空间的话，模拟在本串操作要实现右旋转字符串的功能还是有点困难的。

字符串整体倒序，然后再把分割的两段分别倒叙。

AC1: 自己写函数
```cpp
#include <iostream>
 
using namespace std;
 
void reverse(string& s, int l, int r)
{
    for(int i=l, j=r; i<j; i++, j--)
        swap(s[i], s[j]);
}
 
int main()
{
    int k;
    string s;
    cin>>k>>s;
 
    reverse(s, 0, s.size()-1);
    reverse(s, 0, k-1);
    reverse(s, k, s.size()-1);
 
    cout<<s<<endl;
 
    return 0;
}
```
